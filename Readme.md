# Animation Practice

A personal repository for practicing and experimenting with web animations.

## 🎯 Goal

The goal of this repo is to improve my understanding of animation by building small experiments and recreating different animation techniques.

## 🧪 What I'll Practice

* CSS animations & transitions
* JavaScript animations
* GSAP
* Scroll-based animations
* Page transitions
* Text animations
* Image reveal effects
* Hover interactions
* SVG animations
* WebGL animations
* Shader-based effects
* Smooth scrolling
* Micro-interactions
* 3D animations

## 🛠️ Tech

* HTML
* CSS
* JavaScript
* GSAP
* WebGL
* GLSL
* React (when needed)

```text
animation-practice/

```

## 🚀 Purpose

This is a playground rather than a production project.

I'll use it to:

* Experiment with new animation techniques
* Recreate animations I find interesting
* Understand how animations work under the hood
* Test performance and different approaches
* Build reusable animation patterns
* Develop a better eye for motion and interaction

## 📌 Progress

This repository will continuously evolve as I learn and experiment with new animation techniques.
